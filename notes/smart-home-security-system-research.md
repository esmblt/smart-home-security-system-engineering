# Mini Benchmark

## Typical Features

- Remote Monitoring: Access live video feeds and alerts from your smartphone or tablet.
- Smart Locks: Keyless entry systems that can be controlled remotely
- Video Surveillance: Cameras that provide real-time video and recording capabilities
- Integration with Other Smart Devices: Ability to connect with other smart home devices for enhanced security
- Smartphone Alerts: Receive real-time notifications when security events such as intrusion detection, door opening, motion detection, or system faults occur.

## Stakeholder Needs

- Protection against unauthorized entry
- Fast notification of security events
- Easy system operation
- Reliable alarm detection
- Low false alarm rate

## Users

- Homeowner
- Family members
- Maintenance technician
- Authorized User 

## Use Cases

- Arm the security system
- Disarm the security system
- Receive security notifications
- View camera feed
- Lock and unlock doors remotely
- Review event history
- Configure system settings
- Perform maintenance activities

## Constraints

- Residential use only : The system is intended for private homes and apartments. It is not designed for commercial buildings, factories, or industrial environments.
- Wi-Fi connectivity required : The system relies on a Wi-Fi connection to communicate with the mobile application and send notifications.
- Mobile application required : Users must be able to monitor and control the system through a smartphone application.
- Budget limitations : The system should provide essential security functions without requiring expensive hardware or enterprise-level equipment.
