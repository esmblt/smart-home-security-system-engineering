Create architecture diagrams
Now that you have the system specifications document with all the information and requirements of the Smart Home system, create an architecture diagram using Draw.io(opens in a new tab).


Include the following:

A server, where the Smart Home System manager software will be installed. Add all the components for it to work like database, storage, etc. Remember to add how the server will be accessed (local or cloud)
Controllers: These are devices that the system can use to control physical devices in your home. (i.e. Smart light, smart lock, etc). Remember to add the connectivity technology they use and how they connect to the Smart home system manager software.
Sensors that the system will have, add the connectivity type between the sensors and the manager.
User interaction: Here you can add how the user will interact with the system (i.e. Mobile app, browser, wall mounted screen)
Create SysML diagrams
Create a SysML diagram to define all the different blocks of the Smart Home System and the use cases. Focus on showing the following:

A control unit, which is the central controller of the System. It processes and manages data and serves as an interface for the user with the system.
Sensors (which provide data and serves as triggers for alarms)
Cameras (to record/stream video)
Alarm system (trigger alarms/sound/notifications)
User Interface (how the user interact with the system)
Power supply
Cloud services (to remotely control the system)

These are some of the blocks your Smart home system should have. Feel free to add more if you want!


Also, feel free to create additional diagrams for other things like requirements and their relationships, state machine or sequence diagrams.


You can use plantuml (opens in a new tab)to create the diagrams and submit the plantUML code or create the diagrams using draw.io(opens in a new tab) and upload the created .drawio file.
