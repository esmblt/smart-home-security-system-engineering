Tradeoff evaluation is the process of comparing different design options based on multiple criteria, such as cost, performance, reliability, and risk, to make informed decisions. It involves identifying tradeoffs between competing factors, analyzing their impact, and selecting the best balance to meet system goals.

Create a decision matrix to evaluate different design options for some of the components (i.e. Wireless vs Wired cameras). Focus on the following devices:


Sensors: Select the appropriate criteria to be able to select the best option between 3 different motion sensors, door/window sensors, water leak sensors, etc.


Cameras: Select the appropriate criteria to be able to select the best option between 4 different camera types.


Controllers: These are similar to sensors so you can create a decision matrix that is similar to sensors.


Server and manager: Compare which will be best suitable for your Smart Home system. A local or cloud server. Add all the necessary criteria as this is one of the most important parts of the system.


Note: Remember, cost is not the only criteria you have to consider to create a good decision matrix.

Use the following template(opens in a new tab) to create each one of the decision matrix for sensors, camera, controllers and server/manager. You can create a single .xlsx file with multiple tabs for each decision matrix or one .xlsx file for each case.
