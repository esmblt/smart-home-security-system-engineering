# Design and Validation of a Smart Home Security System

## Project Overview

This repository contains the system engineering artifacts developed for the design and validation of a Smart Home Security System.

The system includes components  motion sensors, cameras, alarm, and a central control unit.

The project covers the following system engineering activities: 
- Development of System Requirements Specification based on IEEE 29148:2018
- Creation of a system architecture model
- Evaluation of design trade-offs
- Development of verification and validation plan
- Preperation of test use cases to evaluate whether the system satisfies usr needs

## Project Workflow and Features

1. System Requirement Specification
2. System Architecture and Design
3. Trade-off Evaluation
4. Verification and Validation
